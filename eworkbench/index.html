How to use and update schematicsBench measurements → notes → share here → GitHub update

1 · Study the measured drawing

Choose an observed schematic for continuity findings. Its JSON, SVG, and unidentified pads are reference records — not editable in the browser. Confirm the power state, probe endpoints, readings, and whether an idea is measured or only suspected.

2 · Try a simulation

Choose a simulation sandbox, edit parts inside CircuitJS1, and press Run/Pause. Save browser draft stores a copy only on this device; Download .txt exports the circuit to keep or share. Reset restores the committed repository model.

3 · Send new measurements

Read the current roadmap step, take measurements with the board in a safe state, and enter results under Field notes. Click Copy update for ChatGPT, then paste it into our chat and attach close-up photos or exported circuit files as needed.

4 · Update the repository

For now, we'll revise the observed netlist, drawing, U1 pad map, and roadmap through GitHub commits/pull requests after reviewing your notes here. The website does not write changes to GitHub. Merge the PR to publish the latest version.

Always distinguish continuity-confirmed nets from guesses and CircuitJS1 component values. Full workbench documentation ↗
